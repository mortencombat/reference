This site is a self-hosted instance of [Reference](https://github.com/Fechin/reference), a collection of cheat
sheets for developers contributed by the open source community and maintained by [Fechin](https://github.com/Fechin).

The cheat sheets themselves are the upstream project's work. This instance packages them for self-hosting: it
runs without advertisements, affiliate links or analytics, and it is configured by whoever runs it.

## Contributing

Found a mistake, or want to add a cheat sheet? Contribute to the upstream project on
[GitHub](https://github.com/Fechin/reference) so that every instance benefits.

## Supporting the original author

If you find these cheat sheets useful, consider [sponsoring Fechin](https://github.com/sponsors/Fechin), who created
and maintains them.
